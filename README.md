# Hydrofoil Telemetry

### Software & Utilities for Hydrofoil Generation

Welcome to the official **Hydrofoil Telemetry (HT)** software release
repository.

Hydrofoil Telemetry develops tools and utilities that expand the
analysis, administration, customization, and advanced functionality
available to Hydrofoil Generation players.

This repository is the official download location for released HT
Windows applications.

------------------------------------------------------------------------

## HT Applications

### HTRTS --- HT Real-Time Solo

Real-time personal sailing telemetry for Hydrofoil Generation
multiplayer sessions.

### HTRTU --- HT Real-Time Umpire

Live race-control, server-control, monitoring, and umpire tools for
advanced Hydrofoil Generation multiplayer use.

### HT Race Course Plotter

A visual desktop course editor for Hydrofoil Generation race courses,
with tools for working with marks, spawns, boundaries, laylines,
ladders, and course geometry.

------------------------------------------------------------------------

## Downloads

Official Setup.exe files for HT applications are available from the

## Installation

1.  Download the setup.exe file for the HT application you want to install.
2.  Run the **Setup.exe**.
3.  Follow the Setup Wizard to complete installation.

------------------------------------------------------------------------

## Windows Security Notice

HT applications are independently developed software and may not be
digitally signed with a commercial Windows code-signing certificate.

Microsoft Defender SmartScreen may therefore display an **unrecognized
publisher** or **Windows protected your PC** message when launching an
installer.

If you downloaded the package from this official Hydrofoil Telemetry
repository, verify that you have the expected HT package before
proceeding.

An actual antivirus or malware detection should be treated differently
from an unknown-publisher warning. If security software reports a
specific malware detection, stop and verify the file before running it.

## About Hydrofoil Telemetry

HT projects include tools for real-time telemetry, post-race analysis,
race and course management, server administration and monitoring, race
control and umpiring, replay analysis, environment and visual
customization, player statistics, and other advanced Hydrofoil
Generation utilities.
